# Credit Card Fraud Detection

## Week 2 – Data Science Internship Project

### Project Overview
This project focuses on detecting fraudulent credit card transactions using machine learning techniques. The dataset was explored, cleaned, analyzed, and used to compare different classification models.

### Tasks Performed
- Imported and explored the dataset
- Performed Exploratory Data Analysis (EDA)
- Checked missing values and duplicates
- Visualized class distribution
- Applied feature scaling
- Trained multiple machine learning models
- Compared model performance
- Saved model comparison results

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### Dataset
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
